# Common Ground

A curated directory of adult dance studios in Chicago, with class schedules, reviews, and filters that help you find a class.

---

## Tech Stack

**Frontend**

- React 19
- React Router 7
- Vite

**Backend**

- Node.js with Express 5
- PostgreSQL via `pg`

**Scraping**

- Puppeteer — headless browser scraping for live class schedules across studio websites (Wix, Squarespace, custom Ribbon widgets)

**Data**

- PostgreSQL database for studios and classes
- `studios.json` snapshot kept in sync with the database for static reads
